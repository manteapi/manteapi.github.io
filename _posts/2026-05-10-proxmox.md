# 🧱 Home Lab Media Infrastructure (Proxmox)

## 🌐 Network Layer

- LAN: 192.168.x.x
- Router:
  - UPnP: ❌ Disabled (recommended)
- Access:
  - SSH from personal PC
  - No public port exposure (LAN-only setup)

---

## 🖥️ Hypervisor Layer

- Platform: Proxmox VE
- Role: Virtualization host for all services
- Runs one main VM for media stack

---

## 🧠 Virtual Machine: Media Server (Ubuntu + Docker)

- OS: Ubuntu Server
- Runtime: Docker + Docker Compose
- Purpose: Central media automation and playback system

---

## 🐳 Docker Stack Overview

### 🎬 Media Server
- Jellyfin (Media playback server)
  - Port: 8096
  - Libraries:
    - /srv/media/movies
    - /srv/media/series

---

### 📥 Download & Automation Stack

- qBittorrent (download engine)
  - Port: 8080
  - Downloads: /srv/media/downloads

- Sonarr (TV automation)
  - Port: 8989
  - Root: /srv/media/series
  - Handles:
    - episode detection
    - renaming
    - moving/hardlinking

- Radarr (movie automation)
  - Port: 7878
  - Root: /srv/media/movies

- Prowlarr (indexer manager)
  - Port: 9696
  - Feeds Sonarr & Radarr

- Flaresolverr
  - Cloudflare bypass for indexers

- Bazarr
  - Subtitle management for movies & series

- Jellyseerr
  - Port: 5055
  - User request interface for Sonarr/Radarr

---

## 📂 Storage Layout

Shared media directory inside VM:


/srv/media/
├── movies/
├── series/
└── downloads/

## 🔄 Data Flow (Automation Pipeline)


Jellyseerr
↓
Sonarr / Radarr
↓
Prowlarr (indexers)
↓
qBittorrent (downloads)
↓
/srv/media/downloads
↓
Sonarr / Radarr import
↓
/srv/media/series + /movies
↓
Jellyfin (playback)


---

## 🎯 System Characteristics

### ✔ Strengths
- Fully containerized stack (Docker)
- Centralized storage (/srv/media)
- Automated media acquisition (Sonarr/Radarr)
- Unified indexer management (Prowlarr)
- Clean separation of roles

### ⚠️ Current Design Constraints
- Single VM dependency
- Shared storage inside VM
- Requires strict path consistency across containers

---

## 🔐 Security Model

- LAN-only access (no public exposure)
- SSH access secured with keys (recommended)
- UPnP disabled on router (recommended)
- No direct internet exposure of internal services

---
